# 24. Interview-Focused Revision List

> This is the short list of topics you should revise before interviews.

## Quick Map

| Area | Must Know |
|---|---|
| Django core | models, ORM, migrations |
| Auth | login, permissions, users |
| Middleware | sessions, signals |
| Security | CSRF, XSS, settings |
| DRF | serializers, viewsets, routers |

## 1) Must-Know Django Topics

- Models and ORM
- Migrations
- Authentication and permissions
- Middleware
- Sessions
- Security
- Testing

## 2) Must-Know DRF Topics

- Serializers
- ViewSets and routers
- Authentication
- Permissions
- Pagination
- Filtering
- Exception handling

## 3) Common Interview Questions

- Explain MVT in Django.
- Difference between `select_related()` and `prefetch_related()`.
- Why use `ModelSerializer`?
- Difference between `APIView` and `ViewSet`.
- How does JWT authentication work?

## Why It Matters in Django

- This is the fastest revision sheet before an interview.
- It helps you focus on the most asked topics first.
